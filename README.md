# kembara-menggapai-kegemilangan
A 2D open-world sailing game set in the Age of Discovery. You are a sea explorer leaving Lisbon to find treasures and a new sea route to the Spice Lands.  Sail a tiny caravel across a real whole-world map. Unexplored waters hide under clouds that clear as you sail. Read the wind, stars, and sea the way sailors did in 1487.
